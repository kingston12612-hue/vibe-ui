# vibe-ui ✨

Лёгкое Android-приложение на Flutter: выбираешь «вайб» — и весь интерфейс
перестраивается под настроение. Анимированные градиенты, дрейфующие блобы,
летающие частицы, стеклянные карточки, **процедурные эмбиент-звуки** и
**дыхательная практика** под каждый вайб.

Никакой логики «про работу» — чистая эстетика и настроение.

## Вайбы (9)

| Вайб | Настроение | Звук |
|------|-----------|------|
| 🌙 Midnight Chill | глубокая ночь, спокойствие | низкий ночной гул |
| 🌇 Sunset Drive | закат, окна вниз | тёплый свелл |
| ☔ Lo-fi Rain | дождь, кофе, лоу-фай биты | дождь с каплями |
| 🌆 Neon City | неон, город после полуночи | синт-дрон (Am) |
| 🌲 Forest Calm | тишина и хвоя | ветер + редкие птицы |
| 🍬 Cotton Candy | пастельные мечты | воздушный C-dur пад |
| 🚀 Deep Space | далеко от дома | космический дрон с биениями |
| 🔥 Campfire | тёплые руки | треск костра |
| 🌌 Aurora | небо в медленном огне | эфирный Cmaj7 пад |

Выбранный вайб и состояние звука сохраняются (shared_preferences)
и восстанавливаются при следующем запуске.

## Фичи

- **Анимированный фон** — CustomPainter: дрейфующие блобы + 26 частиц, всё на каждый кадр
- **Саундскейпы** — 9 звуковых петель, сгенерированных процедурно на numpy
  (никаких сэмплов!), seamless-loop, OGG, ~50 КБ каждый
- **Дыхание 4·4·4** — guided-сессия в ambient-режиме: вдох-пауза-выдох по светящейся орбе, счётчик циклов
- **Стекломорфизм** — карточки, цитаты и кнопки с blur-эффектом
- **Память** — последний вайб + mute переживают перезапуск

## Запуск

Нужен Flutter 3.24+ (Dart 3.5+).

```bash
git clone https://github.com/kingston12612-hue/vibe-ui.git
cd vibe-ui
flutter create . --project-name vibe_ui --platforms android,ios
flutter pub get

# иконка приложения (опционально, из assets/icon/icon.png)
dart run flutter_launcher_icons

flutter run
```

`flutter create .` генерирует платформенные папки (`android/`, `ios/`) —
они не хранятся в репозитории, чтобы проект оставался лёгким.

## Структура

```
lib/
├── main.dart                     # точка входа приложения
├── models/vibe.dart              # модель вайба (градиент, цитата, акцент)
├── data/vibes.dart               # список вайбов — добавь свой сюда
├── services/
│   └── sound_manager.dart        # singleton: эмбиент-звук, mute, prefs
├── screens/
│   ├── home_screen.dart          # сетка карточек + текущий вайб
│   ├── vibe_ambient_screen.dart  # ambient-режим: цитата, звук, дыхание
│   └── breathing_overlay.dart    # дыхательная практика 4·4·4
└── widgets/
    ├── animated_background.dart  # CustomPainter: блобы + частицы
    └── vibe_card.dart            # стеклянная карточка вайба

assets/
├── sounds/                       # 9 OGG-петель (сгенерированы numpy)
└── icon/icon.png                 # AI-иконка приложения
```

## Как добавить свой вайб

1. Объект в `lib/data/vibes.dart`:

```dart
Vibe(
  id: 'volcano',
  name: 'Volcano',
  emoji: '🌋',
  tagline: 'molten heart',
  quote: 'Pressure makes diamonds.',
  gradient: [Color(0xFF200122), Color(0xFF6F0000)],
  accent: Color(0xFFFF6B35),
),
```

2. (Опционально) звук: положи `volcano.ogg` в `assets/sounds/`
   и добавь строку в карту `vibeSounds` в `lib/services/sound_manager.dart`.

Сетка на главном экране, ambient-режим и звук подхватятся автоматически.

## Как генерировались звуки

Все саундскейпы — чистый синтез на Python + numpy: коричневый/белый шум
с фильтрами, синусоидные дроны с детюном (эффект биений), LFO-модуляция,
капли дождя и треск костра из коротких огибающих. Петли сшиты кроссфейдом,
частоты подогнаны под целое число периодов на луп — шов не слышно.
Скрипт из 9 вайбов: см. историю репозитория (`assets/sounds/*.ogg`).

## Идеи для развития

- Дыхательные паттерны на выбор (4·7·8, box breathing)
- Таймер сна: затухание звука через N минут
- Виджет на рабочий стол с текущим вайбом
- Экспорт вайба как обоев для телефона
